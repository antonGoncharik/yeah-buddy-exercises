# yeah-buddy-exercises

Exercise catalog and 180×180 previews (GIF + JPG) for the Yeah Buddy workout app.

## Layout

```
data/yeah-buddy-exercises.json
data/yeah-buddy-exercises.schema.json
images/{id}-{media_id}.jpg
videos/{id}-{media_id}.gif
```

Paths in `image` and `gif_url` are relative to the repo root.

Instructions: English and Russian (`instructions`, `instruction_steps`).
